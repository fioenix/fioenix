# Tools for thoughtful work.

I'm Fioenix, building with [FINOLABS](https://github.com/finolabs) in Ho Chi Minh City, Vietnam.
I work on agent tools, Vietnamese language editing, and research grounded in evidence.

## Selected work

### [Vietnamizer](https://github.com/fioenix/vietnamizer)

An agent skill for natural Vietnamese writing. Edits preserve the meaning, facts, and writer's voice, with guidance tailored to the audience and format.

**Language · Agent skills** &nbsp; / &nbsp; [Get started](https://github.com/fioenix/vietnamizer#cài-nhanh)

### [Ignis](https://github.com/fioenix/fn-ignis)

A self-hosted research harness for testing market hypotheses against evidence from social sources. Makes observations, contrary evidence, and unanswered questions inspectable.

**Research · Python · MCP** &nbsp; / &nbsp; Under development — [source and release status](https://github.com/fioenix/fn-ignis#verification-and-release-status)

### [Huly Skill](https://github.com/fioenix/huly-skill)

A CLI and MCP server that connects agents to Huly project management. Work with tasks, projects, documents, milestones, and comments from an agent workflow.

**Developer tools · TypeScript · MCP** &nbsp; / &nbsp; [Get started](https://github.com/fioenix/huly-skill#install-per-agent)
